本项目 C# 注释里引用需求编号（FR-xxx-NN）时，必须以 docs/requirements/需求文档.md §4.1 的表格为准逐条核对，不得凭"顺序感"猜。

已实锤的坑（2026-10-09 修正 6 处）：任务管理同族方法在 HostFacade 与 TaskRegistry 两处极易整族错位一位——
- 创建=FR-TASK-01（曾被误标 02）
- 编辑=FR-TASK-02（曾被误标 04）
- 删除=FR-TASK-03（曾被误标 05）
- 复制=FR-TASK-04（曾被误标 05/06）
- 持久化=FR-TASK-05、名称唯一=FR-TASK-06、启用禁用=FR-TASK-07

关键词：FR-TASK-01 创建 / FR-TASK-02 编辑 / FR-TASK-03 删除 / FR-TASK-04 复制 / FR-TASK-05 持久化 / FR-TASK-06 名称唯一 / FR-TASK-07 启用禁用 / FR-TASK-08 单实例 / FR-TASK-09 无上限。

写注释前查表，别按顺序猜。
